# Module 07 — Source Metadata Model

## Source Classification
- `GOVERNMENT`: Official market feeds.
- `MARKET`: Mandi / APMC direct feeds.
- `VERIFIED_PARTNER`: Authenticated partner feeds.
- `MANUAL`: Field observations.
- `IMPORTED_DATA`: Telemetry datasets.
- `OTHER`: Other sources.

## Development Data Policy
Development seed records are explicitly identified with `source.name = "Development Reference Seed Data"`. No development data is ever claimed to be official government data.
