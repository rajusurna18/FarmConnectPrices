# FarmConnectPrices Frontend

The web client for **FarmConnectPrices** — *Real Prices. Better Markets. Smarter Decisions.*

---

## Technology Stack

- **Framework:** React 19
- **Language:** TypeScript (Strict mode enabled)
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS v4
- **Routing:** React Router v7
- **HTTP Client:** Axios
- **State Management:** TanStack Query v5
- **Code Quality:** ESLint

---

## Setup & Installation

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Configure Environment Variables:**
   Create a `.env` file based on `.env.example`:
   ```env
   VITE_API_BASE_URL=http://localhost:8080
   ```

---

## Available Commands

- **Development Server:**
  ```bash
  npm run dev
  ```

- **Lint Codebase:**
  ```bash
  npm run lint
  ```
